# CONTENT_MODELS.md
### نماذج المحتوى المؤسسية — المنصة العالمية للتعريف بالإسلام والتعليم الإسلامي

**نوع الوثيقة:** تصميم هندسي مؤسسي (Enterprise Solution Architecture) — تحليل بحت، بلا كود، بلا Prisma Schema، بلا SQL، بلا جداول، بلا APIs، بلا صفحات.
**المرجع الإلزامي:** `Master Project Document`، `Information Architecture`، `Knowledge Architecture` — كل نموذج أدناه امتداد مباشر لكيانات وعلاقات ودورة حياة تلك الوثائق، لا إعادة تعريف لها.
**الغرض:** الإجابة عن السؤال التالي لكل واحد من الـ37 نوع محتوى: *"ما الذي يحتاج هذا الكيان تحديدًا ليكون جاهزًا للتحوّل إلى جدول قاعدة بيانات مؤسسي، دون كتابة ذلك الجدول بعد؟"*

## 0. المبادئ العامة والأنماط الموحَّدة (Cross-Cutting Standards)

هذا القسم يُعرَّف **مرة واحدة فقط** ويُطبَّق ضمنيًا على كل نموذج من النماذج الـ37 أدناه، لتفادي التكرار وضمان الاتساق المؤسسي.

### 0.1 المبادئ الإلزامية العشرة

| المبدأ | ماذا يعني عمليًا لكل نموذج محتوى |
|---|---|
| **UUID/UUIDv7** | كل كيان يُعرَّف بمعرّف UUIDv7 (وليس Integer تسلسليًا) — يضمن ترتيبًا زمنيًا ضمنيًا مع تفادي تكهّن الحجم/التسلسل، وهو ضروري لمعرِّفات موزَّعة عبر مناطق سحابية متعددة (متوافق مع مبدأ "بنية سحابية متعددة المناطق" في المستند التأسيسي). |
| **Versioning** | كل تعديل على محتوى منشور لا يُعدِّل السجل مباشرة، بل ينتج **إصدارًا جديدًا** قابلاً للمقارنة بالإصدار السابق؛ الإصدار المنشور الحالي وحده مرئي للعامة، وما قبله محفوظ للتدقيق والرجوع. |
| **Soft Delete** | لا حذف نهائي فعليًا لأي محتوى تحريري أو مرجعي — يُعلَّم السجل بحالة "محذوف منطقيًا" مع تاريخ ومنفِّذ الحذف، ويبقى قابلاً للاستعادة. الحذف النهائي الفعلي استثناء إداري نادر يتطلب صلاحية `ADMIN` وسببًا موثَّقًا. |
| **Audit Trail** | كل انتقال حالة (إنشاء، تعديل، مراجعة، اعتماد، نشر، أرشفة، حذف) يُسجَّل في سجل تدقيق مستقل: من نفَّذ الإجراء، متى، وما الذي تغيَّر بالضبط — منفصل عن Versioning (الأخير يحفظ *المحتوى*، الأول يحفظ *الفعل*). |
| **Multi-language by Design** | لكل كيان قابل للترجمة، السجل بلغة واحدة هو الوحدة الأساسية، ويُربَط بمجموعة ترجمة تجمع كل النسخ اللغوية لنفس المحتوى المفاهيمي — بحالة نشر مستقلة لكل لغة (قرار موثَّق سابقًا في `PHASE_2_ROADMAP.md`). التفاصيل في القسم 0.5. |
| **SEO First** | كل نموذج محتوى عام (غير داخلي/تشغيلي) يحمل حقول SEO أساسية (عنوان ميتا، وصف ميتا، Slug صديق لمحركات البحث) كجزء أصيل من النموذج لا إضافة لاحقة. |
| **AI Ready** | كل محتوى منشور له معرِّف مستقر وقابل للاستشهاد يمكن للذكاء الاصطناعي الإشارة إليه بدقة؛ وكل محتوى غير منشور (Draft/Review) **غير مرئي** لطبقة استرجاع الذكاء الاصطناعي بنفس القيد المطبَّق على الزوار العاديين. |
| **Search Ready** | كل نموذج يحدِّد صراحة أي حقوله قابلة للفهرسة وأيها للعرض فقط — قرار تصميمي واعٍ لكل حقل، لا فهرسة عشوائية لكل شيء. |
| **Enterprise Scale** | كل علاقة N:M مصمَّمة بافتراض احتمال آلاف أو ملايين السجلات على أي طرف — ينعكس هذا لاحقًا في قرارات الفهرسة عند تصميم قاعدة البيانات الفعلية، لا في هذه الوثيقة. |

### 0.2 الحقول القياسية الموحَّدة (Universal System Fields)

كل نموذج يحمل ضمنيًا: `id` (UUIDv7)، `version`، `status` (حالة دورة الحياة)، `localeGroupId` (يربط النسخ اللغوية)، `language`، `createdAt`/`updatedAt`/`deletedAt`، `createdBy`/`updatedBy`/`reviewedBy`/`approvedBy`/`publishedBy`، `seoSlug`/`seoMetaTitle`/`seoMetaDescription`، `isAiIndexable`، `isSearchIndexed`. لا تُكرَّر هذه في جدول حقول كل نموذج أدناه — تُذكر فقط الحقول **المميِّزة** لكل نموذج.

### 0.3 أنماط دورة الحياة (Lifecycle Patterns)

- **النمط A — دورة تحريرية كاملة:** `Draft → Review → Scholarly Review → Published → Archived` — للمحتوى البشري القابل للخطأ والتحديث.
- **النمط B — بيانات مرجعية مستوردة:** `Imported → Validated → Active → Under Correction` — للنصوص المصدرية الثابتة (القرآن، الحديث كنص، الرواة).
- **النمط C — خط أنابيب الوسائط:** `Uploaded → Processing → Review → Published → Archived`.
- **النمط D — تشغيلي (أشخاص وأماكن):** `Active ↔ Inactive/Suspended`، مع حالة تحقق فرعية `Submitted → Verified/Rejected` للأماكن تحديدًا.
- **النمط E — تصنيف (Taxonomy):** `Active ↔ Deprecated`، مع نسخة مقيَّدة شرعيًا لقيم "الفقه" و"العقيدة" تتطلب اعتماد `SCHOLAR_REVIEWER`.

### 0.4 مصفوفة الأدوار المرجعية

الأدوار السبعة معرَّفة مسبقًا في `config/permissions.ts`: `VISITOR`, `MEMBER`, `STUDENT`, `TEACHER`, `SCHOLAR_REVIEWER`, `COMMUNITY_MODERATOR`, `ADMIN`. Scholar/Author/Translator/Reviewer أدناه **ملفات بيانات**، لا أدوار وصول جديدة.

### 0.5 نمط الترجمة الموحَّد

سجل منفصل بحالة نشر مستقلة لكل لغة، مرتبط بـ`localeGroupId` مشترك. يُذكر لكل نموذج فقط إن كانت القاعدة **قياسية** أو لها **استثناء** (كالفيديو).

### 0.6 نمط البحث الموحَّد

كل نموذج يُفهرَس بحقول أساسية موحَّدة + حقول مميِّزة. القيد الحاكم: **لا يظهر في البحث العام إلا محتوى `Published`**.

### 0.7 نمط الذكاء الاصطناعي الموحَّد

القيد الحاكم: **لا استشهاد إلا بسجل `isAiIndexable = true`**. يُذكر لكل نموذج فقط الاستخدام المميِّز.

## 1. نطاق القرآن (Quran Domain)

### 1.1 Quran
**الوصف:** الكيان الجذري للمصحف ككل — يدعم أكثر من رواية قراءة معتمدة مستقبلاً.
**الحقول المميِّزة:** riwayah (Enum، إلزامي، AI✓) · totalSurahCount (رقم، إلزامي) · totalVerseCount (رقم، إلزامي) · sourceEdition (نص، إلزامي، ترجمة✓، AI✓).
**العلاقات:** 1:N Surah (إلزامية).
**دورة الحياة:** النمط B؛ لا يُؤرشَف أبدًا.
**الصلاحيات:** الإنشاء/التعديل=ADMIN ← المراجعة/الاعتماد=SCHOLAR_REVIEWER ← النشر تلقائي ← لا أرشفة.
**التحقق:** رواية افتراضية واحدة محدَّدة؛ totalSurahCount=114.
**البحث:** غير مباحث مباشرة؛ نطاق تصفية.
**AI:** يحدد سياق الرواية لأي استشهاد قرآني.
**الترجمة:** غير قابل للترجمة؛ فقط اسم الرواية.

### 1.2 Surah
**الوصف:** إحدى سور القرآن الـ114.
**الحقول المميِّزة:** number (رقم 1-114، بحث✓ SEO✓ AI✓ فهرسة✓) · arabicName (نص، بحث✓ SEO✓ AI✓ فهرسة✓) · transliteratedName (بحث✓ SEO✓ فهرسة✓) · translatedName (ترجمة✓ بحث✓ SEO✓ AI✓) · revelationType (Enum، بحث✓ AI✓) · verseCount (مشتق، AI✓) · orderOfRevelation (AI✓).
**العلاقات:** N:1 Quran (إلزامية) · 1:N Verse (إلزامية) · N:M Topic (اختيارية).
**دورة الحياة:** النمط B.
**الصلاحيات:** ADMIN مع مراجعة SCHOLAR_REVIEWER إلزامية لأي تعديل.
**التحقق:** number فريد 1-114؛ verseCount يطابق عدد Verse الفعلي.
**البحث:** كيان تصفح أساسي، إكمال تلقائي.
**AI:** ربط "من أي سورة هذه الآية".
**الترجمة:** translatedName عبر النمط القياسي.

### 1.3 Verse (آية)
**الوصف:** الوحدة الأساسية والأكثر أهمية في النموذج — النص العثماني الثابت، مصدر كل استشهاد قرآني.
**الحقول المميِّزة:** verseNumberInSurah (بحث✓ AI✓ فهرسة✓) · absoluteVerseNumber (بحث✓ SEO✓ AI✓ فهرسة✓) · arabicTextUthmani (بحث✓ AI✓ فهرسة✓) · arabicTextSimple (بحث✓ فهرسة✓) · juzNumber/hizbNumber (بحث✓ فهرسة✓) · pageNumber (بحث✓ فهرسة✓) · sajdahFlag (Boolean، بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:1 Surah (إلزامية) · 1:N Word (إلزامية) · 1:N Translation (اختيارية) · 1:N Tafsir (اختيارية) · N:M Topic/Tag (اختيارية).
**دورة الحياة:** النمط B، الأشد صرامة — انتقال لحالة Under Correction يتطلب موافقة SCHOLAR_REVIEWER مزدوجة.
**الصلاحيات:** استيراد أولي واحد بإشراف ADMIN+SCHOLAR_REVIEWER معًا؛ لا تعديل روتيني لاحق.
**التحقق:** absoluteVerseNumber فريد ومتسلسل (1-6236)؛ مطابقة checksum لمصدر معتمَد.
**البحث:** الوحدة الأساسية للبحث القرآني، نصي + مرجعي مباشر.
**AI:** وحدة الاستشهاد الأساسية — كل استشهاد يُحلّ إلى id آية محدَّد.
**الترجمة:** النص العربي لا يُترجَم أبدًا ضمن هذا الكيان.

### 1.4 Word (كلمة)
**الوصف:** وحدة التحليل اللغوي والصرفي للنص القرآني.
**الحقول المميِّزة:** positionInVerse (بحث✓ AI✓ فهرسة✓) · arabicText (بحث✓ AI✓ فهرسة✓) · transliteration (بحث✓ فهرسة✓) · morphologicalTag (Enum، بحث✓ AI✓ فهرسة✓) · wordGloss (ترجمة✓ بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:1 Verse (إلزامية) · N:1 Root (اختيارية).
**دورة الحياة:** النمط B.
**الصلاحيات:** ADMIN+SCHOLAR_REVIEWER فقط.
**التحقق:** positionInVerse متسلسل بلا فجوة؛ morphologicalTag من قاموس مضبوط.
**البحث:** بحث على مستوى الكلمة، ربط بالبحث عبر الجذر.
**AI:** أساس الإجابة على أسئلة لغوية دقيقة.
**الترجمة:** wordGloss عبر النمط القياسي.

### 1.5 Root (جذر)
**الوصف:** الجذر اللغوي العربي الذي تنتمي إليه كلمة أو أكثر.
**الحقول المميِّزة:** rootLetters (بحث✓ SEO✓ AI✓ فهرسة✓) · generalMeaning (ترجمة✓ بحث✓ AI✓ فهرسة✓) · occurrenceCount (مشتق، بحث✓ AI✓ فهرسة✓).
**العلاقات:** 1:N Word (إلزامية من جهة الجذر).
**دورة الحياة:** النمط B.
**الصلاحيات:** ADMIN+SCHOLAR_REVIEWER.
**التحقق:** rootLetters مُطبَّع وفريد.
**البحث:** نقطة دخول للبحث الصرفي.
**AI:** محور اجتياز الرسم البياني المعرفي.
**الترجمة:** generalMeaning عبر النمط القياسي.

### 1.6 Translation (ترجمة معاني القرآن)
**الوصف:** ترجمة معنى آية إلى لغة أخرى — كيان تفسيري بشري مستقل عن النص العربي.
**الحقول المميِّزة:** translatedText (بحث✓ SEO✓ AI✓ فهرسة✓) · translatorReference (بحث✓ AI✓) · methodologyNote (ترجمة✓) · footnotes (ترجمة✓ بحث✓ AI✓ فهرسة✓) · disclaimerAccepted (Boolean، يجب true).
**العلاقات:** N:1 Verse (إلزامية) · N:1 Language (إلزامية) · N:1 Translator (إلزامية).
**دورة الحياة:** النمط A كاملاً.
**الصلاحيات:** الإنشاء=TEACHER/Translator ← المراجعة/الاعتماد=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN/SCHOLAR_REVIEWER.
**التحقق:** disclaimerAccepted=true قبل الاعتماد؛ ربط بآية واحدة فقط؛ حد أدنى للطول.
**البحث:** بحث كامل بلغتها؛ جسر بحث عابر للغات.
**AI:** إجابات بلغات غير عربية مع استشهاد مرتبط بمعرِّف الآية.
**الترجمة:** هذا الكيان هو نفسه نسخة الترجمة.

### 1.7 Tafsir (تفسير)
**الوصف:** شرح علمي لآية أو مجموعة آيات، منسوب لمفسِّر محدَّد.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · bodyText (ترجمة✓ بحث✓ AI✓ فهرسة✓) · scopeType (Enum، بحث✓ AI✓ فهرسة✓) · sourceType (Enum، بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:M Verse (إلزامية، ≥1) · N:1 Scholar (إلزامية) · N:1 Book (اختيارية) · N:M Topic (اختيارية).
**دورة الحياة:** النمط A.
**الصلاحيات:** الإنشاء=SCHOLAR/TEACHER ← المراجعة+الاعتماد=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN.
**التحقق:** استشهاد بآية واحدة على الأقل؛ حد أدنى لطول bodyText؛ إسناد المصدر إلزامي.
**البحث:** بحث نصي كامل، تصفية حسب المفسِّر/المصدر.
**AI:** المصدر الأساسي للإجابة عن معنى الآية، ترتيب حسب موثوقية المفسِّر.
**الترجمة:** سجل منفصل لكل لغة، دورة حياة مستقلة.

### 1.8 Recitation (تلاوة)
**الوصف:** تسجيل صوتي لتلاوة القرآن، مرتبط بقارئ ورواية محدَّدين.
**الحقول المميِّزة:** reciterReference (بحث✓ SEO✓ فهرسة✓) · audioReference (إلزامي) · riwayah (Enum، بحث✓ AI✓ فهرسة✓) · scopeType (Enum، بحث✓ فهرسة✓) · durationSeconds (رقم).
**العلاقات:** N:1 Surah أو N:M Verse (اختيارية) · N:1 Audio (إلزامية) · N:1 القارئ (إلزامية).
**دورة الحياة:** النمط C + بوابة تحقق من صحة الرواية عبر SCHOLAR_REVIEWER.
**الصلاحيات:** الرفع=ADMIN/TEACHER ← المراجعة=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN.
**التحقق:** تطابق التسجيل مع الرواية المعلَنة؛ durationSeconds>0؛ قارئ محدَّد.
**البحث:** تصفية حسب القارئ/الرواية.
**AI:** غير مستشهَد نصيًا؛ يُقترَح كوسيط صوتي مرافق.
**الترجمة:** بيانات القارئ قابلة للترجمة؛ التسجيل نفسه غير لغوي.

## 2. نطاق السنة (Sunnah Domain)

### 2.1 Hadith (حديث)
**الوصف:** نص حديثي منسوب للنبي ﷺ مع درجته العلمية — من أكثر الكيانات حساسية في النموذج.
**الحقول المميِّزة:** matnText (بحث✓ SEO✓ AI✓ فهرسة✓) · grade (Enum، بحث✓ SEO✓ AI✓ فهرسة✓) · gradingScholarReference (إلزامي، AI✓) · topicClassification (بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:1 HadithCollection (إلزامية) · N:M Narrator (إلزامية، مرتَّبة) · N:1 Book (إلزامية) · N:M Topic (إلزامية).
**دورة الحياة:** النمط B للنص؛ تعديل grade يمر بنمط A مصغَّر (SCHOLAR_REVIEWER إلزامي).
**الصلاحيات:** الاستيراد=ADMIN ← تعديل الدرجة حصرًا=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN.
**التحقق:** grade من قاموس مضبوط مع عالِم مدرِّج موثَّق؛ matnText إلزامي؛ سلسلة إسناد واحدة على الأقل.
**البحث:** بحث نصي كامل + تصفية حسب الدرجة/المجموعة/الراوي.
**AI:** مصدر استشهاد أساسي — الدرجة تُعرَض دائمًا، لا تُحذَف أبدًا.
**الترجمة:** نمط مشابه لترجمة القرآن (سجل منفصل لكل لغة، امتداد مستقبلي).

### 2.2 Hadith Collection (مجموعة حديثية)
**الوصف:** المصدر الكتابي الأساسي للحديث (مثل صحيح البخاري).
**الحقول المميِّزة:** collectionName (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · compilerReference (بحث✓ AI✓ فهرسة✓) · era (ترجمة✓ AI✓) · totalHadithCount (مشتق).
**العلاقات:** 1:N Hadith (إلزامية) · N:1 Scholar (إلزامية).
**دورة الحياة:** النمط B.
**الصلاحيات:** ADMIN+SCHOLAR_REVIEWER فقط.
**التحقق:** المُصنِّف سجل Scholar تاريخي موثَّق؛ totalHadithCount يُراجَع دوريًا.
**البحث:** وجه تصفية أساسي عند بحث الحديث.
**AI:** سياق موثوقية لترتيب/ثقة الاستشهاد.
**الترجمة:** collectionName/era عبر النمط القياسي.

### 2.3 Narrator (راوٍ)
**الوصف:** شخص ضمن سلسلة إسناد حديث، يخضع لعلم الجرح والتعديل.
**الحقول المميِّزة:** fullName (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · generationLayer (Enum، بحث✓ AI✓ فهرسة✓) · reliabilityAssessment (نص مقيَّد، ترجمة✓ AI✓) · birthEra/deathEra.
**العلاقات:** N:M Hadith (سلسلة إسناد مرتَّبة).
**دورة الحياة:** النمط B.
**الصلاحيات:** ADMIN+SCHOLAR_REVIEWER فقط.
**التحقق:** reliabilityAssessment يستشهد بمصدر كلاسيكي محدَّد، لا حكمًا تحريريًا حرًا.
**البحث:** بحث بالحديث حسب الراوي.
**AI:** اجتياز رسم سلسلة الإسناد لإجابات واعية بالموثوقية.
**الترجمة:** fullName وreliabilityAssessment عبر النمط القياسي.

### 2.4 Scholar Commentary (شرح/تعليق عالِم)
**الوصف:** تعليق من عالِم على حديث/فتوى/موضوع عام — أوسع من Tafsir.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · bodyText (ترجمة✓ بحث✓ AI✓ فهرسة✓) · subjectType (Enum، بحث✓ AI✓ فهرسة✓) · relatedEntityReference (Polymorphic، إلزامي، AI✓).
**العلاقات:** N:1 Scholar (إلزامية) · مرجع متعدد الأنواع لـ Hadith/Fatwa/Topic/Article (إلزامية) · N:M Topic (اختيارية).
**دورة الحياة:** النمط A.
**الصلاحيات:** الإنشاء=SCHOLAR/TEACHER ← المراجعة+الاعتماد=SCHOLAR_REVIEWER ← الأرشفة=ADMIN.
**التحقق:** الكيان المرجعي موجود ومنشور فعليًا؛ حد أدنى لطول bodyText.
**البحث:** بحث نصي كامل، يظهر مرفقًا بالكيان المرتبط (توسيع واعٍ بالعلاقة).
**AI:** مصدر استشهاد ثانوي، أدنى من Tafsir/Fatwa المباشرين.
**الترجمة:** سجل منفصل لكل لغة.

## 3. نطاق العلوم الإسلامية والتعليم (Islamic Sciences & Education)

### 3.1 Fatwa (فتوى)
**الوصف:** أعلى درجات الحساسية العلمية — إجابة شرعية موثَّقة لسؤال فقهي محدَّد.
**الحقول المميِّزة:** questionText (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · answerText (ترجمة✓ بحث✓ AI✓ فهرسة✓) · fiqhSchool (بحث✓ AI✓ فهرسة✓) · issueDate (فهرسة✓) · referenceCitations (اختياري موصى به، AI✓).
**العلاقات:** N:1 Scholar (إلزامية) · N:M Topic/Fiqh (إلزامية) · N:M Verse/Hadith (اختيارية).
**دورة الحياة:** النمط A — البوابة الأشد صرامة، لا اختصار للاعتماد الشرعي أبدًا.
**الصلاحيات:** الإنشاء=SCHOLAR حصرًا ← المراجعة=SCHOLAR_REVIEWER ← الاعتماد=SCHOLAR_REVIEWER مختلف عن المُصدِر ← النشر تلقائي ← الأرشفة=ADMIN/SCHOLAR_REVIEWER.
**التحقق:** questionText/answerText حد أدنى للطول؛ fiqhSchool إلزامي؛ مُصدِر يحمل دور SCHOLAR فعليًا.
**البحث:** بحث نصي بأولوية عالية للمطابقة الدقيقة، تصفية حسب المذهب/الموضوع.
**AI:** نقطة تحويل إلزامية — سؤال فقهي دقيق يُوجَّه لفتوى موجودة أو إحالة لعالِم بشري.
**الترجمة:** سجل منفصل لكل لغة، مع توصية باعتماد شرعي مستقل لكل لغة.

### 3.2 Article (مقالة)
**الوصف:** النموذج الأكثر مرونة — يخدم "عن الإسلام"، الفقه العام، السيرة عبر التصنيف لا كيانات منفصلة.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · bodyText (ترجمة✓ بحث✓ AI✓ فهرسة✓) · excerpt (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · featuredImageReference (SEO✓) · estimatedReadTime (مشتق).
**العلاقات:** N:1 Author/Scholar (إلزامية) · N:M Verse/Hadith/Fatwa (اختيارية) · N:1 Category (إلزامية) · N:M Topic/Tag (اختيارية).
**دورة الحياة:** النمط A.
**الصلاحيات:** الإنشاء=TEACHER ← المراجعة+الاعتماد=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN.
**التحقق:** title بحد أقصى موصى به (SEO)؛ excerpt إلزامي؛ حد أدنى لطول bodyText.
**البحث:** أساس البحث النصي العام، وزن SEO مرتفع.
**AI:** مصدر استشهاد عام، خاصة لأسئلة "عن الإسلام".
**الترجمة:** سجل منفصل لكل لغة، دورة حياة مستقلة.

### 3.3 Book (كتاب)
**الوصف:** مصدر مرجعي كامل، قد يكون مصدر تخريج لأحاديث أو أساسًا لتفسير.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · authorReference (بحث✓ AI✓ فهرسة✓) · publicationEra (AI✓) · bookType (Enum، بحث✓ AI✓ فهرسة✓) · digitalFileReference (اختياري) · isbn (اختياري).
**العلاقات:** N:1 Author/Scholar (إلزامية) · 1:N Hadith (اختيارية) · 1:N Tafsir (اختيارية) · N:M Topic (اختيارية).
**دورة الحياة:** النمط A للبيانات الوصفية؛ يقترب من B إن كان استيرادًا بحتًا.
**الصلاحيات:** الإنشاء=ADMIN/TEACHER ← المراجعة+الاعتماد=SCHOLAR_REVIEWER ← الأرشفة=ADMIN.
**التحقق:** authorReference إلزامي؛ bookType من قاموس مضبوط.
**البحث:** فهرس/تصفح، تصفية حسب النوع/المؤلف/الحقبة.
**AI:** مرجعية "مصدر الأصل" عند استشهاد Hadith/Tafsir بكتاب محدَّد.
**الترجمة:** العنوان قابل للترجمة؛ الملف الرقمي قد يكون سجل Attachment منفصل لكل إصدار لغوي.

### 3.4 Course (دورة)
**الوصف:** مسار تعليمي متكامل يضم دروسًا متسلسلة.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · description (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · level (بحث✓ AI✓ فهرسة✓) · targetAudience (بحث✓ AI✓ فهرسة✓) · certificateEligible (Boolean، بحث✓ فهرسة✓) · coverImageReference (SEO✓).
**العلاقات:** 1:N Lesson (إلزامية) · N:1 Author/Scholar/Teacher (إلزامية) · N:M Topic/Category (اختيارية) · N:M User (تسجيل، اختيارية).
**دورة الحياة:** النمط A. قيد خاص: لا نشر قبل نشر درس واحد على الأقل.
**الصلاحيات:** الإنشاء=TEACHER ← المراجعة+الاعتماد=SCHOLAR_REVIEWER ← النشر تلقائي ← الأرشفة=ADMIN/TEACHER.
**التحقق:** level/targetAudience إلزاميان؛ لا نشر بدون ≥1 Lesson منشور.
**البحث:** كتالوج، تصفية حسب المستوى/الجمهور/الموضوع.
**AI:** يغذّي توصية مسارات التعلّم المخصَّصة.
**الترجمة:** سجل منفصل لكل لغة، دورة حياة مستقلة.

### 3.5 Lesson (درس)
**الوصف:** وحدة تعليمية واحدة ضمن دورة، لا توجد بمعزل عنها.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ AI✓ فهرسة✓) · orderIndex (رقم، AI✓) · contentType (Enum، بحث✓ فهرسة✓) · bodyText (اختياري، ترجمة✓ بحث✓ AI✓ فهرسة✓) · estimatedDuration.
**العلاقات:** N:1 Course (إلزامية) · N:M Video/Audio/Article (≥1 إلزامي) · N:1 Quiz (اختيارية).
**دورة الحياة:** النمط A، مرتبط بدورة حياة Course.
**الصلاحيات:** نفس صلاحيات Course.
**التحقق:** orderIndex فريد ضمن الدورة؛ مرجع محتوى واحد على الأقل.
**البحث:** يظهر عادة ضمن سياق Course.
**AI:** وحدة تتبّع التقدُّم للتوصية الشخصية.
**الترجمة:** سجل منفصل لكل لغة.

### 3.6 Quiz (اختبار)
**الوصف:** تقييم معرفي مرتبط بدرس أو نهاية دورة.
**الحقول المميِّزة:** title (ترجمة✓) · passingScorePercentage (رقم) · attemptLimit (اختياري) · timeLimitMinutes (اختياري).
**العلاقات:** N:1 Lesson (اختيارية) أو N:1 Course (اختيارية) · 1:N Question (إلزامية) · N:M User (محاولات، اختيارية).
**دورة الحياة:** النمط A مخفَّف — SCHOLAR_REVIEWER إلزامي فقط إن مسّ فقهًا/عقيدة، وإلا مراجعة أقران.
**الصلاحيات:** الإنشاء=TEACHER ← المراجعة/الاعتماد=SCHOLAR_REVIEWER أو أقران حسب الحساسية ← الأرشفة=ADMIN.
**التحقق:** passingScorePercentage بين 0-100؛ ≥1 Question قبل النشر.
**البحث:** غير مفهرَس عامةً (خلف بوابة التسجيل).
**AI:** يحدِّد الفجوات المعرفية للتعلّم التكيّفي.
**الترجمة:** سجل منفصل لكل لغة، قد يحتاج مراجعة ثقافية إضافية.

### 3.7 Question (سؤال — ضمن اختبار)
**الوصف:** سؤال واحد ضمن Quiz، يختلف عن مفهوم سؤال-وجواب المعرفي العام.
**الحقول المميِّزة:** questionText (ترجمة✓) · questionType (Enum) · points (رقم) · orderIndex (رقم).
**العلاقات:** N:1 Quiz (إلزامية) · 1:N Answer (إلزامية).
**دورة الحياة:** يتبع بوابة Quiz، لا يُنشَر مستقلاً.
**الصلاحيات:** نفس Quiz.
**التحقق:** ≥2 خيارات Answer للاختيار من متعدد؛ إجابة صحيحة محدَّدة بوضوح.
**البحث:** غير قابل للبحث (داخلي).
**AI:** مرشَّح مستقبلي لتوليد أسئلة تدريب (قدرة مستقبلية مُعلَّمة، خارج النطاق الحالي).
**الترجمة:** سجل منفصل لكل لغة، مرتبط بلغة Quiz.

### 3.8 Answer (إجابة — خيار لسؤال اختبار)
**الوصف:** أحد خيارات الإجابة على Question.
**الحقول المميِّزة:** answerText (ترجمة✓) · isCorrect (Boolean) · explanationText (اختياري، ترجمة✓ AI✓) · orderIndex.
**العلاقات:** N:1 Question (إلزامية).
**دورة الحياة:** يتبع Question/Quiz.
**الصلاحيات:** نفس Question.
**التحقق:** answerText إلزامي؛ منطق isCorrect مطابق لقيود questionType.
**البحث:** غير قابل للبحث.
**AI:** explanationText قابل للاستخدام لتغذية راجعة مخصَّصة.
**الترجمة:** سجل منفصل لكل لغة.

## 4. نطاق الوسائط (Media Domain)

### 4.1 Video (فيديو)
**الوصف:** وسيط مرئي مستقل أو مرتبط بدرس/مقالة/فعالية.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · fileReference (إلزامي) · durationSeconds (فهرسة✓) · resolution · subtitleTracks (آلية الترجمة، AI✓) · transcriptText (اختياري، ترجمة✓ بحث✓ AI✓ فهرسة✓) · thumbnailReference (إلزامي، SEO✓).
**العلاقات:** N:M Lesson/Article/Event (اختيارية) · N:1 Language (إلزامية) · N:1 Uploader/User (إلزامية).
**دورة الحياة:** النمط C.
**الصلاحيات:** الرفع=TEACHER/ADMIN ← المراجعة=SCHOLAR_REVIEWER+فحص تقني منفصل ← النشر تلقائي ← الأرشفة=ADMIN.
**التحقق:** قيود صيغة/حجم؛ durationSeconds>0؛ صورة مصغَّرة إلزامية قبل النشر.
**البحث:** بحث نصي عبر transcriptText إن وُجد؛ تصفية حسب اللغة/الترجمة.
**AI:** transcriptText هو المصدر النصي القابل للاستشهاد؛ الفيديو نفسه غير مقروء مباشرة.
**الترجمة:** استثناء — عبر subtitleTracks، لا سجل Video منفصل لكل لغة.

### 4.2 Audio (مقطع صوتي)
**الوصف:** وسيط صوتي مستقل (محاضرة، بودكاست)، ويخدم Recitation كحالة خاصة.
**الحقول المميِّزة:** title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · fileReference (إلزامي) · durationSeconds (فهرسة✓) · speakerReference (اختياري، بحث✓ AI✓ فهرسة✓) · transcriptText (اختياري، ترجمة✓ بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:M Lesson/Article/Recitation · N:1 Language (إلزامية).
**دورة الحياة:** النمط C.
**الصلاحيات:** نفس Video.
**التحقق:** durationSeconds>0؛ قيود صيغة/حجم.
**البحث:** عبر transcriptText إن وُجد.
**AI:** نفس منطق Video.
**الترجمة:** إما سجل Audio منفصل (إعادة تسجيل) أو ترجمة transcriptText فقط، حسب سياق كل حالة.

### 4.3 Image (صورة)
**الوصف:** صورة كغلاف أو ضمن محتوى — الأكثر إلزامية من ناحية إمكانية الوصول.
**الحقول المميِّزة:** fileReference (إلزامي) · altText (إلزامي غير قابل للتنازل، ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · caption (اختياري، ترجمة✓ بحث✓ AI✓ فهرسة✓) · dimensions.
**العلاقات:** N:M أي كيان محتوى.
**دورة الحياة:** النمط C مخفَّف (Uploaded→Published مباشرة عادة، مراجعة فقط إن كان حساسًا).
**الصلاحيات:** الرفع=أي منشئ محتوى ← المراجعة عند الحاجة=SCHOLAR_REVIEWER/ADMIN ← الأرشفة=ADMIN.
**التحقق:** altText إلزامي بلا استثناء؛ قيود صيغة/حجم؛ فحص إجرائي لحقوق الملكية.
**البحث:** altText مفهرَس لبحث الصور/إمكانية الوصول.
**AI:** altText هو الوصف النصي الأساسي القابل للقراءة آليًا.
**الترجمة:** altText/caption عبر النمط القياسي.

### 4.4 Attachment (مرفق)
**الوصف:** ملف قابل للتنزيل (PDF، عرض تقديمي، إنفوجراف).
**الحقول المميِّزة:** fileReference (إلزامي) · fileType (Enum، بحث✓ فهرسة✓) · fileSizeBytes · title (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · description (اختياري، ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓).
**العلاقات:** N:1 كيان مالك (مرجع متعدد الأنواع).
**دورة الحياة:** النمط C.
**الصلاحيات:** نفس Video/Image.
**التحقق:** fileType من قائمة مسموحة فقط (قيد أمني)؛ حد أقصى للحجم.
**البحث:** title/description مفهرَسان؛ استخراج نص من الملف قدرة مستقبلية مُعلَّمة.
**AI:** description قابل للاستشهاد؛ استخراج محتوى الملف قدرة مستقبلية.
**الترجمة:** سجل Attachment منفصل لكل لغة (ملف مُعاد رفعه)، لا بيانات وصفية فوق ملف مشترك.

## 5. نطاق الأشخاص (People Domain)

### 5.1 Scholar (عالِم)
**الوصف:** شخصية علمية معتبرة — تاريخية أو عضو حي في هيئة الإشراف.
**الحقول المميِّزة:** fullName (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · biography (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · specialization (بحث✓ AI✓ فهرسة✓) · era (Enum، بحث✓ AI✓ فهرسة✓) · credentialsSummary (ترجمة✓ AI✓) · isLivingMember (Boolean، AI✓).
**العلاقات:** 1:N Tafsir/Fatwa/ScholarCommentary/Article (اختيارية) · N:1 User (إن isLivingMember=true) · N:M Islamic Center (اختيارية).
**دورة الحياة:** النمط D للملف + بوابة النمط A لنص السيرة.
**الصلاحيات:** الإنشاء/التعديل=ADMIN ← المراجعة+الاعتماد (للسيرة)=SCHOLAR_REVIEWER ← الأرشفة=ADMIN.
**التحقق:** fullName إلزامي؛ إن isLivingMember=true يجب الربط بمستخدم بالدور المناسب.
**البحث:** دليل قابل للتصفح، بحث بالاسم/التخصص.
**AI:** إشارة ترجيح موثوقية للمحتوى المعتمَد من هذا العالِم.
**الترجمة:** biography/credentialsSummary عبر النمط القياسي.

### 5.2 Author (مؤلف)
**الوصف:** كاتب محتوى عام دون اشتراط صفة عالِم شرعي رسمية.
**الحقول المميِّزة:** fullName (ترجمة✓ بحث✓ SEO✓ فهرسة✓) · biography (اختياري، ترجمة✓ بحث✓ SEO✓ فهرسة✓) · penName (اختياري، بحث✓ فهرسة✓).
**العلاقات:** 1:N Article/Book (تأليف) · N:1 User (إلزامية).
**دورة الحياة:** النمط D.
**الصلاحيات:** الإنشاء/التعديل=صاحب الملف أو ADMIN؛ لا اعتماد شرعي مطلوب للملف نفسه.
**التحقق:** الربط بحساب User إلزامي.
**البحث:** عرض في سطر الكاتب، بحث بالاسم.
**AI:** يُستخدَم للعزو فقط، لا كإشارة ترجيح موثوقية (خلافًا لـ Scholar).
**الترجمة:** biography عبر النمط القياسي.

### 5.3 Translator (مترجم)
**الوصف:** شخص معتمَد لإنتاج ترجمات محتوى.
**الحقول المميِّزة:** fullName (ترجمة✓ بحث✓ SEO✓ فهرسة✓) · biography (اختياري، ترجمة✓ بحث✓ فهرسة✓) · certifiedLanguages (إلزامي، بحث✓ AI✓ فهرسة✓) · credentialsSummary (اختياري، ترجمة✓ AI✓).
**العلاقات:** 1:N Translation/Tafsir(مترجَم)/Fatwa(مترجَمة) · N:1 User (إلزامية).
**دورة الحياة:** النمط D.
**الصلاحيات:** الإنشاء/التعديل=صاحب الملف أو ADMIN؛ توثيق certifiedLanguages يتطلب تأكيد ADMIN.
**التحقق:** certifiedLanguages غير فارغة.
**البحث:** دليل بحث حسب زوج اللغة.
**AI:** يُستخدَم للإشارة إلى مصدر/ثقة الترجمة.
**الترجمة:** biography عبر النمط القياسي.

### 5.4 Reviewer (مراجع)
**الوصف:** ملف بيانات لحامل صلاحية SCHOLAR_REVIEWER لأغراض التدقيق والعزو — متمايز عن الدور نفسه.
**الحقول المميِّزة:** fullName (ترجمة✓) · reviewScope (إلزامي، AI✓) · activeStatus (Boolean).
**العلاقات:** N:1 User (إلزامية) · مرجعية عكسية من كل سجل تدقيق في كل الكيانات الأخرى.
**دورة الحياة:** النمط D.
**الصلاحيات:** الإنشاء/التعديل=ADMIN حصرًا.
**التحقق:** reviewScope غير فارغ؛ الربط بمستخدم يحمل دور SCHOLAR_REVIEWER فعليًا.
**البحث:** داخلي فقط.
**AI:** غير قابل للاستشهاد؛ يتحقق داخليًا من أن المراجِع اعتمَد ضمن نطاق صلاحيته.
**الترجمة:** غير منطبق.

### 5.5 User (مستخدم)
**الوصف:** معرَّف مسبقًا بالكامل في طبقة الأساس؛ يُذكَر هنا للسياق العلائقي فقط، دون إعادة تعريف.
**الحقول المميِّزة:** (غير مُعرَّفة من جديد — راجع طبقة الأساس المعتمَدة).
**العلاقات:** محور مركزي — تسجيل↔Course، محاولة↔Quiz، تأليف↔Article/Book، ربط اختياري بـ Scholar/Author/Translator/Reviewer.
**دورة الحياة:** النمط D.
**الصلاحيات:** تعديل الملف الشخصي=صاحبه؛ تعيين الأدوار=ADMIN حصرًا.
**التحقق:** فريدية البريد الإلكتروني (مُطبَّقة مسبقًا).
**البحث:** غير قابل للبحث العام (خصوصية).
**AI:** سياق تخصيص فقط، لا يُستخدَم كمصدر معرفة قابل للاستشهاد أبدًا.
**الترجمة:** غير منطبق (تفضيل لغة واجهة فقط).

## 6. نطاق الأماكن (Places Domain)

### 6.1 Mosque (مسجد)
**الوصف:** مسجد فعلي يظهر عبر دليل "أقرب مسجد" — كيان تشغيلي/مجتمعي لا تحريري.
**الحقول المميِّزة:** name (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · geoLocation (إلزامي، بحث✓ AI✓ فهرسة✓) · address (ترجمة✓ بحث✓ SEO✓ فهرسة✓) · prayerTimeSource (Enum، AI✓) · verificationStatus (Enum، بحث✓ AI✓ فهرسة✓) · contactInfo (اختياري).
**العلاقات:** N:1 City (إلزامية) · N:M Islamic Center (اختيارية) · N:M User (اختيارية).
**دورة الحياة:** النمط D مع تدفق تحقق فرعي Submitted→Verified/Rejected.
**الصلاحيات:** التقديم=أي MEMBER ← التحقق=COMMUNITY_MODERATOR/ADMIN ← التعديل=مُقدِّم الطلب حتى التحقق ثم ADMIN ← الأرشفة=ADMIN.
**التحقق:** geoLocation إلزامي وصحيح؛ name إلزامي؛ فحص تكرار موصى به.
**البحث:** كيان بحث جغرافي أساسي.
**AI:** ليس مصدر استشهاد؛ يُستخدَم لإجابات مرتبطة بالموقع.
**الترجمة:** name/address عبر النمط القياسي.

### 6.2 Islamic Center (مركز إسلامي)
**الوصف:** مركز إسلامي/دعوي أوسع وظيفيًا من المسجد.
**الحقول المميِّزة:** name (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · geoLocation (إلزامي، بحث✓ AI✓ فهرسة✓) · servicesOffered (إلزامي، بحث✓ AI✓ فهرسة✓) · contactInfo (اختياري) · verificationStatus (Enum، بحث✓ AI✓ فهرسة✓).
**العلاقات:** N:1 City (إلزامية) · 1:N Event (اختيارية) · N:M Scholar (اختيارية).
**دورة الحياة:** نفس تدفق Mosque.
**الصلاحيات:** نفس Mosque.
**التحقق:** نفس Mosque + servicesOffered من قاموس مضبوط.
**البحث:** بحث جغرافي مع تصفية حسب نوع الخدمة.
**AI:** إجابات مرتبطة بالموقع/نوع الخدمة.
**الترجمة:** name وتسميات servicesOffered عبر النمط القياسي.

### 6.3 Country (دولة)
**الوصف:** بيانات مرجعية جغرافية على أعلى مستوى.
**الحقول المميِّزة:** isoCode (إلزامي، بحث✓ AI✓ فهرسة✓) · nameLocalized (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · region (بحث✓ فهرسة✓).
**العلاقات:** 1:N City (إلزامية).
**دورة الحياة:** النمط E.
**الصلاحيات:** ADMIN فقط.
**التحقق:** isoCode صالح حسب ISO 3166-1.
**البحث:** وجه تصفية للبحث الجغرافي.
**AI:** سياق تحديد الموقع الجغرافي.
**الترجمة:** nameLocalized إلزامي لكل لغة نشطة.

### 6.4 City (مدينة)
**الوصف:** أساس حساب أوقات الصلاة بدقة محلية.
**الحقول المميِّزة:** nameLocalized (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · geoLocation (إلزامي، بحث✓ AI✓ فهرسة✓) · timezoneIdentifier (إلزامي، AI✓).
**العلاقات:** N:1 Country (إلزامية) · 1:N Mosque/Islamic Center (اختيارية) · 1:N User (اختيارية).
**دورة الحياة:** النمط E؛ تقديم مجتمعي ممكن رهن تحقق ADMIN.
**الصلاحيات:** الإنشاء=ADMIN؛ التقديم المجتمعي=أي MEMBER رهن اعتماد ADMIN.
**التحقق:** ربط بدولة صالح إلزامي؛ timezoneIdentifier منطقة IANA صالحة.
**البحث:** وجه تصفية جغرافي، إكمال تلقائي.
**AI:** سياق حساب أوقات الصلاة والإجابات المرتبطة بالموقع.
**الترجمة:** nameLocalized عبر النمط القياسي.

## 7. نطاق النظام (System / Taxonomy Domain)

### 7.1 Category (تصنيف رئيسي)
**الوصف:** التصنيف الهرمي الأعلى — كل محتوى ينتمي لتصنيف رئيسي واحد فقط.
**الحقول المميِّزة:** nameLocalized (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · parentCategory (ذاتي، اختياري، بحث✓ AI✓ فهرسة✓) · iconReference (اختياري) · sortOrder (رقم).
**العلاقات:** ذاتية N:1 (أب) · 1:N أي كيان محتوى (إلزامية، واحد فقط).
**دورة الحياة:** النمط E، مع نسخة مقيَّدة شرعيًا لشجرة الفقه/العقيدة.
**الصلاحيات:** الإنشاء/التعديل العام=ADMIN؛ شجرة الفقه/العقيدة=ADMIN+SCHOLAR_REVIEWER معًا.
**التحقق:** عمق أقصى 3 مستويات؛ nameLocalized إلزامي لكل لغة نشطة.
**البحث:** وجه التنقّل/التصفية الأساسي.
**AI:** تحديد نطاق الإجابة حسب التصنيف.
**الترجمة:** إلزامي لكل لغة نشطة بلا استثناء (بنية تنقّل حرجة).

### 7.2 Tag (وسم)
**الوصف:** كلمة مفتاحية حرة غير هرمية — أخف أوجه التصنيف حوكمةً.
**الحقول المميِّزة:** nameLocalized (ترجمة✓ بحث✓ AI✓ فهرسة✓) · usageCount (مشتق، فهرسة✓).
**العلاقات:** N:M أي كيان محتوى (حرة، بلا حد).
**دورة الحياة:** النمط E، بلا بوابة شرعية.
**الصلاحيات:** الإنشاء=أي TEACHER أثناء التأليف ← الدمج/الحذف=ADMIN.
**التحقق:** كشف تكرار غير حساس للتشكيل/الحالة.
**البحث:** وجه تصفية ثانوي، سحابة وسوم.
**AI:** إشارة موضوعية خفيفة، وزن أقل من Category/Topic.
**الترجمة:** لكل لغة، غير مُلزَم بمطابقة 1:1 عبر اللغات.

### 7.3 Topic (موضوع)
**الوصف:** تصنيف موضوعي أدق يغطي 8 من الأوجه التسعة المعرَّفة في وثيقة Knowledge Architecture.
**الحقول المميِّزة:** nameLocalized (ترجمة✓ بحث✓ SEO✓ AI✓ فهرسة✓) · parentTopic (ذاتي، اختياري، بحث✓ AI✓ فهرسة✓) · facetType (Enum إلزامي، بحث✓ AI✓ فهرسة✓).
**العلاقات:** ذاتية N:1 (أب) · N:M أي كيان محتوى (إلزامية، ≥1).
**دورة الحياة:** نفس نمط Category — النسخة المقيَّدة شرعيًا عند facetType∈{فقه، عقيدة}.
**الصلاحيات:** نفس Category.
**التحقق:** facetType إلزامي من القيم الثمانية؛ عمق الهرمية حسب اصطلاح كل وجه.
**البحث:** وجه التصفية الأساسي للبحث المُوجَّه بالأوجه.
**AI:** الإشارة الأساسية لتوجيه استرجاع الذكاء الاصطناعي عبر الأوجه الثمانية.
**الترجمة:** إلزامي لكل لغة نشطة.

### 7.4 Language (لغة)
**الوصف:** كيان نظامي يُشار إليه من كل كيان قابل للترجمة.
**الحقول المميِّزة:** isoCode (إلزامي، بحث✓ SEO✓ AI✓ فهرسة✓) · nameLocalized (ترجمة✓ بحث✓ فهرسة✓) · direction (Enum إلزامي، AI✓) · isActive (Boolean، بحث✓ AI✓ فهرسة✓).
**العلاقات:** يُشار إليه (N:1) من كل كيان قابل للترجمة.
**دورة الحياة:** النمط E، ADMIN حصرًا.
**الصلاحيات:** ADMIN فقط.
**التحقق:** isoCode صالح؛ direction مضبوط بدقة قبل isActive=true (يحكم آلية getDirection في طبقة الأساس).
**البحث:** وجه تصفية في كل استعلام بحث تقريبًا.
**AI:** يحدد نطاق لغة توليد الإجابة.
**الترجمة:** nameLocalized ذاتي المرجعية — لكل لغة اسم بكل لغة أخرى.
